关于 · ABOUT

一个可以慢慢长大的科普档案。

Біртіндеп өсіп келе жатқан ғылыми идеялар мұрағаты.

中哈科普把三样东西放在同一页：一部能直接播放的短片、一段中文与哈萨克语的概念解释、一份能复现它的提示词。没有后台，没有数据库，没有构建步骤。

这个站做什么Бұл сайт не істейді

科普视频看完很容易「好像懂了」，关掉页面就忘了。这里把同一件事拆成三层：先用 88 秒的动画建立直觉，再用中文把概念、原理和边界写清楚，最后用哈萨克语做对照，方便中文或哈萨克语读者互相校准。

每部片子还附一份生成提示词。它不是宣传文案，而是一份制作说明：时间线、配色语义、科学护栏、编码参数、验收清单。公开提示词的意思是：别人可以照着做一部新的，也可以指出我们哪里没说清。

站点本身是纯静态 HTML。双击任何一个页面都能离线打开；发布到 GitHub Pages 后，每部新片只需要增加一个页面和一条首页条目。

关于中哈双语Екі тіл туралы

视频本身的字幕是中文 / 英文；本站额外提供中文 / 哈萨克语的概念对照。哈萨克语部分以准确传达概念为目标，尽量不用生硬的直译；它仍是一份教学初稿，术语与语气都欢迎指正。

Жоба туралы Бейнедегі субтитрлер — қытай және ағылшын тілдерінде; сайтта оларға қазақша мәтін қосылған. Қазақша нұсқа — оқу жобасы: мағынаны жеткізеді, бірақ әдеби редакцияға үміткер емес. Ескертулер құпталады.

之所以把两种语言放在同一页而不是做语言切换，是因为这个项目的读者常常同时使用两种语言：中文读者可以借哈萨克语核对术语，哈萨克语读者可以借中文理解语境。

如何新增一部视频Жаңа фильмді қалай қосу

整个流程只有四步，不需要安装任何工具：

  1. 准备素材

    一个 .mp4（建议 H.264 / yuv420p，16:9），一张 16:9 封面，以及 0:00、0:08……等章节的缩略图。封面和缩略图可以直接从成片抽帧。

  2. 放进对应目录

    视频放 assets/videos/，封面与缩略图放 assets/img/，提示词原文放 assets/prompts/。文件名用英文小写与连字符，避免不同系统之间的编码问题。

  3. 复制并修改视频页

    把 videos/resnet.html 复制成 videos/your-topic.html，替换标题、哈萨克语标题、正文、章节按钮与素材路径。章节按钮上的 data-chapter 就是跳转秒数。

  4. 更新首页并发布

    在首页视频库追加一张卡片，在「后续选题」里删掉对应条目。提交到 GitHub 后，Pages 会在下一次构建时自动更新。

小提示 新页面里的相对路径要按层级写：videos/ 下的页面引用素材时用 ../assets/。封面图保持 1280×720 左右即可，过大的原图会拖慢首屏。

技术说明Техникалық жағы

全站只有 HTML、CSS 和一小段原生 JavaScript。没有框架、没有外部字体、没有分析脚本，也没有 Cookie。视频使用浏览器原生 <video> 播放；复制提示词、章节跳转、滚动高亮都是渐进增强，禁用 JavaScript 后正文与播放仍然可用。

页面使用系统字体栈（Segoe UI / 微软雅黑 / PingFang / Noto Sans），因此在离线和不同系统上都不会出现字体请求失败导致的闪烁。整个站点可以拷贝到 U 盘里直接打开。

项目选择原因
托管GitHub Pages免费、纯静态、与仓库同源，改完即发布
构建无页面即文件，减少维护成本
双语同页对照读者常同时使用中文与哈萨克语，切换反而增加负担
