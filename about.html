About · 项目说明

把科学讲清楚，也用两种语言讲清楚。

Понятно о науке на двух языках.

中俄科普是一个纯静态的中俄双语科普站：每部短片配中文与俄语解释，以及可复现的制作提示词。没有后台，没有数据库，没有构建步骤。

项目是什么Что это за проект?

科普视频看完很容易「好像懂了」，关掉页面就忘了。这里把同一件事拆成三层：先用 88 秒动画建立直觉，再用中文把概念、原理和边界写清楚，最后用俄语做对照，方便中文或俄语读者互相校准。

每部片子还附一份生成提示词。它不是宣传文案，而是一份制作说明：时间线、配色语义、科学护栏、编码参数、验收清单。公开提示词，意味着别人可以照着做一部新的，也可以指出我们哪里没说清。

站点本身是纯静态 HTML。双击任何页面都能离线打开；发布到 GitHub Pages 后，每部新片只需要增加一个页面和一条首页条目。

关于中俄双语О двух языках

视频本身的字幕是中文 / 英文；本站额外提供中文 / 俄语的概念对照。俄语部分以准确传达概念为目标，尽量不用生硬的直译；它仍是一份教学初稿，术语与语气都欢迎指正。

Русский Субтитры в видео представлены на китайском и английском языках. На сайте доступны пояснения на русском языке. Русский текст предназначен для учебного использования; замечания по терминологии и переводу приветствуются.

之所以把两种语言放在同一页而不是做语言切换，是因为这个项目的读者常常同时使用两种语言：中文读者可以借俄语核对术语，俄语读者可以借中文理解语境。

内容与制作Содержание и создание

视频、封面与插图由项目作者使用 AI 工具生成、剪辑与校对；概念文本参考原始论文与公开教材后重写。内容用于科普学习，不构成专业结论或建议。

如何新增一部视频Как добавить новое видео

整个流程只有四步，不需要安装任何工具：

  1. 准备素材

    一个 .mp4（建议 H.264 / yuv420p，16:9），一张 16:9 封面，以及 0:00、0:08……等章节的缩略图。封面和缩略图可以直接从成片抽帧。

  2. 放进对应目录

    视频放 assets/videos/，封面与缩略图放 assets/img/，提示词原文放 assets/prompts/。文件名用英文小写与连字符，避免不同系统之间的编码问题。

  3. 复制并修改视频页

    把 videos/resnet.html 复制成 videos/your-topic.html，替换标题、俄语标题、正文、章节按钮与素材路径。章节按钮上的 data-chapter 就是跳转秒数。

  4. 更新首页并发布

    在首页「最新视频」区域替换或追加条目，在「后续选题」里删掉对应条目。提交到 GitHub 后，Pages 会在下一次构建时自动更新。

路径提示：videos/ 下的页面引用素材时使用 ../assets/；首页与 concepts.html 使用 assets/。封面图保持 1280×720 左右即可，过大的原图会拖慢首屏。

技术说明Техническая часть

全站只有 HTML、CSS 和一小段原生 JavaScript。没有框架、没有外部字体、没有分析脚本，也没有 Cookie。视频使用浏览器原生 <video> 播放；复制、章节跳转、收藏和点击粒子都是渐进增强，禁用 JavaScript 后正文与播放仍然可用。

页面使用系统字体栈（Inter / Noto Sans SC / 微软雅黑 / PingFang），因此在离线和不同系统上都不会出现字体请求失败导致的闪烁。整个站点可以拷贝到 U 盘里直接打开。

项目选择原因
托管GitHub Pages免费、纯静态、与仓库同源，改完即发布
构建无页面即文件，减少维护成本
双语同页对照读者常同时使用中文与俄语，切换反而增加负担
